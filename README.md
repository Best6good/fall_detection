# 毫米波雷达摔倒检测演示模块

---

## 1. 模块定位与功能概述

本模块是毫米波雷达摔倒检测系统的**最小可行演示原型**，核心目标是验证"点云生成→预处理→特征提取→摔倒检测→可视化报警"完整技术链路的可行性。

**模块边界**：
- 不包含真实雷达硬件驱动
- 不包含深度学习模型
- 不包含后端服务与数据库
- 专注于算法验证和可视化演示

**最新更新**：
- ✅ 引入 `HumanState` 枚举统一状态管理（代替散落字符串）
- ✅ 统计滤波向量化（O(n²) → broadcast，性能大幅提升）
- ✅ 修复倒地检测被高度滤波器吞掉的算法缺陷
- ✅ `_update_frame` 按功能分拆 try 块（UI 异常不影响检测逻辑）
- ✅ 修复 Space 键冲突（Space 仅启动，Ctrl+Space 停止）
- ✅ 清理死代码、未使用变量、冗余 draw() 调用

## 5. 核心数据结构

### 5.1 点云数据格式

```python
# 点云数组格式: (N, 4)
# 每列: [x, y, z, velocity_z]
points = np.array([
    [0.1, 0.2, 1.5, 0.0],   # x位置, y位置, z高度, 垂直速度
    [0.12, 0.21, 1.48, -0.5],
    ...
])
```

### 5.2 人体骨架结构

点云基于16个关键关节生成：
```
头部(head) → 颈部(neck) → 胸部(chest) → 腰部(waist)
胸部 → 左肩(left_shoulder) → 左肘(left_elbow) → 左手(left_hand)
胸部 → 右肩(right_shoulder) → 右肘(right_elbow) → 右手(right_hand)
腰部 → 左髋(left_hip) → 左膝(left_knee) → 左脚(left_foot)
腰部 → 右髋(right_hip) → 右膝(right_knee) → 右脚(right_foot)
```

### 5.3 人体状态定义

状态通过 `config.HumanState` 枚举管理（`STANDING`/`WALKING`/`FALLING`/`FALLEN`），全项目统一引用，杜绝拼写错误。

| 状态 | 说明 | 中心高度 | 垂直速度 | 速度特征 |
|------|------|----------|----------|----------|
| `STANDING` | 站立 | ~1.65m | ~0 m/s | 几乎静止 |
| `WALKING` | 行走 | ~1.65m | 脚部±0.08m/s | 手臂、腿部摆动 |
| `FALLING` | 摔倒中 | 1.65m→0.15m | -1.2 m/s | 快速下降 |
| `FALLEN` | 倒地 | ~0.15m | ~0 m/s | 静止 |

## 7. 核心算法

### 7.1 点云生成算法

**毫米波雷达特性模拟**：
- 使用T分布生成点云（尾部更长，更稀疏）
- 添加RCS稀疏性（随机丢弃20-30%的点）
- 地面阻力效应（靠近地面的点速度受阻力影响）
- 摔倒旋转效应（身体倾斜时的旋转变形）

### 7.2 骨架推断算法

基于点云处理的骨架识别流程：
```
点云 → 高度分层分析 → 部位特征提取 → 骨架结构推理 → 误差注入
```

**骨架关节颜色**：与点云颜色对应（viridis颜色映射），高处关节偏暖（黄色），低处关节偏冷（紫色）

### 7.3 摔倒检测算法

**多特征融合检测**：
| 特征 | 权重 | 阈值/条件 |
|------|------|-----------|
| 高度阈值 | 40% | < 0.4m |
| 速度阈值 | 30% | < -0.6m/s |
| 高度变化率 | 30% | > 5cm/帧 |

**置信度判定**：综合评分 ≥ 60% 触发摔倒判定

### 7.4 宠物识别过滤

防止将猫/狗等小动物误识别为人体：
- **高度过滤**：0.1-0.5m范围内标记为疑似宠物
- **速度判断**：有明显向下速度（< -0.3m/s）的可能是摔倒的人
- **惩罚机制**：疑似宠物置信度降低30%

## 8. 报警机制

### 8.1 检测条件

摔倒检测满足以下条件之一即触发报警：

1. **状态触发**：模拟器状态为 `fallen`（倒地）
2. **阈值触发**：连续N帧满足置信度 ≥ 60%

### 8.2 报警效果

| 效果类型 | 表现 |
|----------|------|
| **顶部报警条** | 红色闪烁（0.5秒间隔），显示报警提示 |
| **点云颜色** | 正常(viridis) → 摔倒(OrRd) → 倒地(纯红色闪烁) |
| **轨迹线** | 白色正常 → 红色加粗（线宽4） |
| **报警标记** | 半透明红色圆形标记（半径0.5m） |
| **声音报警** | Windows蜂鸣声 |
| **曲线标记** | 红色竖线 + 半透明区域填充 |

### 8.3 报警确认

点击"确认报警"按钮后：
- 报警条变为灰色常亮
- 点云恢复正常颜色
- 所有按钮恢复可用
- 曲线恢复更新

## 11. 性能优化

| 优化项 | 实现方式 |
|--------|----------|
| **统计滤波向量化** | Python循环 O(n²) → NumPy broadcast O(n log n) |
| **减少冗余重绘** | 合并 trajectory/center_trajectory 的 draw() 调用，每帧减少 2 次重绘 |
| **colormap 缓存** | viridis/OrRd 色表在初始化时获取，避免每帧重新加载 |
| **帧率优化** | 使用 `draw()` 替代 `draw_idle()`，强制立即重绘 |
| **关闭不必要功能** | 禁用Matplotlib工具栏、交互模式 |
| **字体配置** | 预加载中文字体，避免运行时加载 |
